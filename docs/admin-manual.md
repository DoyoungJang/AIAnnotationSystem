# SonoLabel 관리자 매뉴얼

SonoLabel은 관리자 권한을 두 단계로 분리합니다.

| 역할 | 화면 표시 | 권한 범위 |
|---|---|---|
| Sudo 관리자 (`ADMINISTRATOR`) | 관리자 > 프로젝트 관리, 사용자 관리 | 모든 프로젝트 조회·관리, 사용자 생성, 프로젝트 관리자 지정 |
| 프로젝트 관리자 (`PROJECT_MANAGER`) | 관리자 > 프로젝트 관리 | 자신이 생성했거나 멤버로 지정된 프로젝트만 관리 |

라벨러·검수자·관찰자에게는 **관리자** 메뉴가 표시되지 않으며, 프로젝트 생성·영상 등록·작업 배정 기능에도 서버가 접근을 거부합니다.

## 1. 사용자 계정 생성

1. Sudo 관리자 계정으로 로그인합니다.
2. 왼쪽 **관리자** 메뉴를 엽니다.
3. **사용자 관리** 탭을 선택합니다.
4. 로그인 아이디, 표시 이름, 역할, 12자 이상의 초기 비밀번호를 입력합니다.
5. **계정 생성**을 누릅니다.

프로젝트 관리자는 사용자 계정을 만들 수 없습니다. 계정은 개인별로 발급하고 공용 계정을 사용하지 마십시오.

## 2. 역할 선택 기준

- **Sudo 관리자**: 시스템과 계정 전체를 관리해야 하는 최소 인원에게만 부여합니다.
- **프로젝트 관리자**: 프로젝트 생성, 라벨 스키마, 데이터 등록, 작업 배정 담당자에게 부여합니다.
- **라벨러**: 배정받은 영상에 Annotation을 작성합니다.
- **검수자**: 제출된 Annotation을 승인하거나 수정 요청합니다.
- **관찰자**: 허용된 범위의 현황만 확인합니다.

## 3. 프로젝트 관리자 지정

1. 먼저 **사용자 관리**에서 역할이 **프로젝트 관리자**인 계정을 생성합니다.
2. **프로젝트 관리** 탭에서 프로젝트를 선택합니다.
3. **프로젝트 멤버**의 선택 상자에서 관리자를 고릅니다.
4. **관리자 지정**을 누릅니다.

지정된 프로젝트 관리자는 해당 프로젝트만 목록에서 볼 수 있습니다. 다른 프로젝트에는 접근할 수 없습니다. 프로젝트 관리자가 직접 생성한 프로젝트에는 생성자가 자동으로 멤버로 등록됩니다.

## 4. 프로젝트 멤버 추가

Sudo 관리자와 프로젝트 관리자는 **프로젝트 관리 > 프로젝트 멤버**에서 사용자를 선택하고 **멤버 추가**를 눌러 참여자를 등록할 수 있습니다.

- Sudo 관리자는 프로젝트 관리자, 라벨러, 검수자, 관찰자를 추가할 수 있습니다.
- 프로젝트 관리자는 라벨러, 검수자, 관찰자를 추가할 수 있습니다.
- 프로젝트 관리자는 다른 프로젝트 관리자나 Sudo 관리자를 추가할 수 없습니다.
- 프로젝트 관리 화면에는 현재 로그인한 관리자가 추가할 수 있는 계정만 표시됩니다.

## 5. 영상 등록과 작업 배정

프로젝트 선택 후 라벨 스키마를 게시하고 영상을 등록합니다. 기존에 등록된 영상은 페이지를 다시 열어도 모두 조회됩니다. 같은 파일을 다시 등록하면 중복으로 제외되지만 기존 영상 목록은 유지됩니다.

각 영상 카드에서 라벨러와 선택적 검수자를 지정한 뒤 **배정**을 누릅니다. 성공 메시지가 표시되어야 배정이 완료된 것입니다. 오류가 표시되면 계정 역할과 프로젝트 접근 권한을 확인하십시오.

## 6. 보안 운영 원칙

- 운영 전 `.env`의 `SECRET_KEY`와 초기 관리자 비밀번호를 변경합니다.
- Sudo 관리자 수를 최소화하고 일상 프로젝트 운영에는 프로젝트 관리자 계정을 사용합니다.
- DICOM 개인정보 태그 의심 표시가 있는 영상은 배정 전에 익명화와 burned-in text 검사를 완료합니다.
- 환자 식별정보를 사용자명, 프로젝트명, 설명에 입력하지 않습니다.
- 작업이 끝나면 로그아웃하고 개인 계정을 공유하지 않습니다.
