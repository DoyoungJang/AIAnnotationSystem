# SonoLabel 사용자 매뉴얼

이 문서는 SonoLabel MVP 웹 화면을 사용하는 라벨러, 검수자, 프로젝트 관리자를 위한 안내서입니다. 서버 설치와 실행은 [README](../README.md), 계정·운영 관리는 [관리자 매뉴얼](admin-manual.md)을 참고하십시오.

## 1. 사용 전 확인

### 권장 환경

- Chrome 또는 Microsoft Edge 최신 버전
- 1280×800 이상의 화면. 라벨링 작업은 1920×1080 이상을 권장합니다.
- 안정적인 기관 내부 네트워크
- 기관 관리자가 발급한 개인 계정

의료영상이 포함된 화면을 개인 PC에 저장하거나 캡처하지 마십시오. 공용 계정을 사용하지 말고 작업을 마친 뒤 반드시 로그아웃하십시오.

### 역할별 주요 기능

| 역할 | 주요 기능 |
|---|---|
| Sudo 관리자 | 모든 프로젝트와 사용자 계정 관리, 프로젝트 관리자 지정 |
| 프로젝트 관리자 | 참여 프로젝트 관리, 라벨 스키마 게시, 데이터 등록, 작업 배정 |
| Annotator | 배정된 작업 열기, Annotation 작성·저장·제출, 수정 요청 작업 재작업 |
| Reviewer | 제출된 작업 열람, 승인 또는 수정 요청 |
| Observer | 허용된 프로젝트와 승인 결과 읽기 전용 조회 |

화면에 메뉴가 보이더라도 서버 권한이 없으면 작업이 거부됩니다. 프로젝트 권한이 필요하면 관리자에게 요청하십시오.

프로젝트 관리자는 **관리자 > 프로젝트 관리 > 프로젝트 멤버**에서 라벨러, 검수자, 관찰자를 프로젝트에 직접 추가할 수 있습니다. 다른 관리자 계정 지정과 사용자 계정 생성은 Sudo 관리자만 할 수 있습니다.

## 2. 접속과 로그인

1. 관리자가 안내한 SonoLabel 주소를 브라우저에서 엽니다.
   - 자동 실행 스크립트 기본 주소: `http://서버주소:5173`
   - Docker Compose 기본 주소: `http://서버주소:8080`
2. `아이디`와 `비밀번호`를 입력합니다.
3. **안전하게 로그인**을 누릅니다.
4. 로그인 후 상단의 사용자 이름과 역할이 올바른지 확인합니다.

로그인에 5회 연속 실패하면 계정이 잠길 수 있습니다. 반복해서 시도하지 말고 관리자에게 잠금 해제를 요청하십시오.

작업을 마치면 왼쪽 아래 사용자 영역의 로그아웃 아이콘을 누릅니다. 브라우저 창만 닫는 것보다 로그아웃을 권장합니다.

## 3. 기본 화면 구성

왼쪽 메뉴는 다음 네 영역으로 구성됩니다.

- **개요**: 프로젝트 수, 내 작업, 검수 대기 수, 승인 Annotation과 최근 작업을 확인합니다.
- **관리자**: Sudo 관리자와 프로젝트 관리자에게만 표시됩니다. 프로젝트, 라벨 스키마, 데이터 등록과 작업 배정을 관리합니다. Sudo 관리자에게는 사용자 관리 탭도 표시됩니다.
- **내 작업**: 본인에게 배정된 Annotation 작업을 엽니다.
- **검수**: Reviewer에게 배정된 제출 작업을 확인합니다.

작업 상태는 카드와 목록에 표시됩니다.

| 상태 | 의미 | 사용자의 다음 행동 |
|---|---|---|
| `ASSIGNED` | 새로 배정됨 | 작업을 열어 시작합니다. |
| `IN_PROGRESS` | 작업 잠금을 획득하고 편집 중 | Annotation을 작성합니다. |
| `DRAFT` | 저장된 임시 작업 | 내용을 확인하고 계속 작업하거나 제출합니다. |
| `SUBMITTED` | 검수자에게 제출됨 | 검수 결과를 기다립니다. |
| `CHANGES_REQUESTED` | 수정 요청됨 | 작업을 다시 열어 수정 후 재제출합니다. |
| `APPROVED` | 검수 승인됨 | 읽기 전용이며 직접 수정할 수 없습니다. |
| `REJECTED` | 검수에서 거부됨 | 관리자 또는 검수자에게 처리 방침을 확인합니다. |

## 4. 라벨러 작업 절차

### 4.1 작업 열기

1. 왼쪽 메뉴에서 **내 작업**을 선택합니다.
2. 작업 카드에서 상태, 우선순위와 Annotation 버전을 확인합니다.
3. 작업 카드를 눌러 라벨링 화면을 엽니다.
4. 영상이 표시되고 상단 상태가 `IN_PROGRESS`인지 확인합니다.

작업을 열면 편집 잠금이 설정되고 주기적으로 갱신됩니다. 다른 사용자가 같은 작업을 편집 중이면 작업을 열 수 없다는 메시지가 표시됩니다. 이 경우 작업 목록으로 돌아가 잠시 후 다시 시도하십시오.

### 4.2 라벨링 화면

- **상단**: 작업 상태, 저장 상태, 수동 저장과 제출 버튼
- **왼쪽**: 현재 Series와 Frame thumbnail
- **가운데**: 초음파 영상 Viewer와 도구 모음
- **오른쪽**: 라벨 목록, Classification, 생성된 Annotation 목록
- **하단**: 파일명, 원본 해상도, Zoom 비율, 좌표계

화면 확대·축소와 이동은 표시 방법만 변경하며 저장 좌표는 항상 원본 영상 픽셀 기준입니다.

### 4.3 영상 확대와 이동

- 마우스 휠을 위로 움직이면 확대, 아래로 움직이면 축소됩니다.
- **이동** 도구를 선택하고 영상을 드래그하면 화면 위치를 이동합니다.
- 도구 모음의 `+`, `-` 버튼으로 단계별 확대·축소할 수 있습니다.
- **화면 맞춤** 버튼을 누르면 영상 전체가 Viewer 안에 맞춰집니다.

### 4.4 Classification

1. 오른쪽 **CLASSIFICATION** 영역에서 해당 분류 항목을 찾습니다.
2. 체크박스를 선택합니다.
3. 선택을 취소하려면 같은 체크박스를 다시 누릅니다.

프로젝트 스키마에 여러 Classification 라벨이 있으면 필요한 항목을 각각 선택합니다.

### 4.5 Bounding Box

1. 오른쪽 라벨 목록에서 `bbox` 유형 라벨을 선택하거나 `W`를 누릅니다.
2. 객체의 한쪽 모서리에서 반대쪽 모서리까지 드래그합니다.
3. 마우스를 놓으면 Bounding Box가 생성됩니다.
4. 잘못 생성했다면 오른쪽 Annotation 목록의 `×`로 삭제하거나 Undo를 사용합니다.

영상 경계를 벗어나는 좌표는 서버 저장 단계에서 거부됩니다.

### 4.6 Polygon

1. 오른쪽에서 `polygon` 유형 라벨을 선택하거나 `P`를 누릅니다.
2. 객체 경계를 따라 점을 차례로 클릭합니다.
3. 마지막 점에서 더블 클릭하면 Polygon이 닫히고 생성됩니다.
4. Polygon은 최소 3개 점이 필요합니다.

완성 전에 잘못 시작했다면 다른 도구를 선택한 뒤 다시 시작하십시오. 완성 후에는 Annotation 목록에서 삭제하고 다시 그릴 수 있습니다.

### 4.7 Brush Mask

1. 오른쪽에서 `brush` 유형 라벨을 선택하거나 `B`를 누릅니다.
2. 상단의 Brush 크기 슬라이더로 굵기를 조절합니다.
3. 영상 위에서 마우스를 누른 채 원하는 영역을 칠합니다.
4. 마우스를 놓으면 한 개의 Brush stroke Annotation이 생성됩니다.
5. 여러 번 칠하면 각 stroke가 별도 Annotation으로 목록에 추가됩니다.

현재 MVP에서는 Brush 영역의 일부만 Eraser로 지우는 기능이 완성되지 않았습니다. 잘못 칠한 stroke는 오른쪽 목록의 `×`로 삭제한 뒤 다시 그리십시오.

### 4.8 Annotation 삭제, Undo와 Redo

- 오른쪽 **ANNOTATIONS** 목록의 `×`를 누르면 해당 Annotation을 삭제합니다.
- 상단 Undo 버튼으로 직전 변경을 되돌립니다.
- 상단 Redo 버튼으로 되돌린 변경을 다시 적용합니다.

Undo/Redo 이력은 현재 작업 화면을 벗어나면 초기화됩니다. 저장된 과거 버전은 서버에 별도 보존됩니다.

## 5. 저장과 제출

### 자동 저장

Annotation 변경 후 약 1.2초 동안 추가 입력이 없으면 자동 저장됩니다. 상단 저장 상태를 확인하십시오.

| 표시 | 의미 | 조치 |
|---|---|---|
| `변경 없음` | 저장할 변경이 없음 | 추가 조치가 필요 없습니다. |
| `저장 중…` | 서버로 전송 중 | 다른 화면으로 이동하지 마십시오. |
| `저장됨` | 서버 저장 완료 | 정상적으로 계속 작업할 수 있습니다. |
| `오프라인 임시 저장` | 브라우저에 임시 보관됨 | 네트워크 복구 후 **저장**을 누르십시오. |
| `버전 충돌` | 서버에 더 최신 버전이 있음 | 덮어쓰지 말고 작업 목록으로 돌아가 다시 여십시오. |
| `저장 실패` | 서버가 저장하지 못함 | 오류 메시지를 확인하고 다시 저장하십시오. |

중요한 변경 후에는 `Ctrl+S` 또는 상단 **저장** 버튼을 눌러 `저장됨`을 확인하십시오.

### 제출

1. 필수 라벨과 Annotation이 모두 입력되었는지 확인합니다.
2. 상단 상태가 `저장됨`인지 확인합니다.
3. **제출** 버튼 또는 `Ctrl+Enter`를 누릅니다.
4. 상태가 `SUBMITTED`로 변경되면 제출이 완료된 것입니다.

제출한 작업은 검수 결과가 나오기 전까지 수정할 수 없습니다.

## 6. 검수자 작업 절차

1. Reviewer 계정으로 로그인합니다.
2. 왼쪽 메뉴에서 **검수**를 선택합니다.
3. `SUBMITTED` 상태의 작업 카드를 엽니다.
4. Viewer, Classification과 Annotation 목록을 확인합니다. 검수 화면은 읽기 전용입니다.
5. 문제가 없으면 **승인**을 누릅니다.
6. 수정이 필요하면 **수정 요청**을 누르고 검수 의견을 입력합니다.

승인된 작업은 `APPROVED`, 수정 요청한 작업은 `CHANGES_REQUESTED` 상태가 됩니다. 수정 요청을 받은 라벨러는 **내 작업**에서 해당 작업을 다시 열고 수정·저장·재제출합니다.

## 7. 프로젝트 관리자 작업 절차

### 프로젝트 생성

1. **관리자** 메뉴의 **프로젝트 관리** 탭을 엽니다.
2. 새 프로젝트 이름과 설명을 입력합니다.
3. **생성**을 누릅니다.

### 기본 라벨 스키마 게시

1. 왼쪽 프로젝트 목록에서 프로젝트를 선택합니다.
2. **기본 스키마 게시**를 누릅니다.
3. 태아 머리 Polygon, 표준 단면 Classification, 해부학 ROI BBox, Brush 분할 라벨이 게시됩니다.

게시된 스키마는 재현성을 위해 직접 덮어쓰지 않고 새 버전으로 관리합니다.

### 분과별 라벨 프리셋 저장 및 불러오기

1. **분과별 라벨 프리셋**에서 `영상의학과`처럼 사용할 분과 폴더를 만들거나 엽니다.
2. 필요한 경우 현재 폴더 안에 `유방`, `갑상선` 같은 하위 폴더를 만듭니다.
3. 현재 프로젝트의 라벨 항목을 재사용하려면 프리셋 이름을 입력하고 **현재 초안 저장**을 누릅니다.
4. 저장된 프리셋의 **불러오기**를 누르면 프리셋의 라벨 항목이 현재 프로젝트 초안에 복사됩니다.
5. 라벨 코드, 도구, 색상과 필수 여부를 확인한 뒤 **새 버전 게시**를 누릅니다.

불러오기는 편집 중인 초안을 교체하지만 게시된 버전은 즉시 바꾸지 않습니다. 잘못 불러온 경우 **게시 버전으로 되돌리기**를 누를 수 있습니다. 프리셋 폴더 삭제는 하위 항목까지 함께 삭제하므로 확인 창을 주의해서 읽으십시오.

### 영상 등록

1. 선택한 프로젝트의 **초음파 영상 등록** 영역으로 이동합니다.
2. 몇 개의 파일만 올릴 때는 **파일 선택 등록**에서 데이터셋 이름과 PNG, JPG, JPEG, BMP, TIFF 또는 DICOM 파일을 선택한 뒤 **선택 파일 등록**을 누릅니다.
3. PC 폴더 전체를 올릴 때는 **폴더 전체 등록**의 폴더 선택 입력을 누르고 원하는 최상위 폴더를 선택합니다.
4. 선택한 폴더 이름이 데이터셋 이름으로 자동 입력되는지 확인하고 **폴더 구조 그대로 등록**을 누릅니다.
5. 등록 수, 중복 제외 수, 미지원 파일 제외 수를 확인합니다.
6. **등록 영상 및 작업 배정**에서 영상이 원래의 `최상위 폴더/하위 폴더` 경로별로 묶여 있는지 확인합니다.

폴더 선택은 관리 권한이 있는 사용자에게만 제공됩니다. 브라우저는 사용자가 선택한 폴더 안의 파일만 읽으며 PC의 절대 경로는 서버로 전송하지 않습니다. 서버는 원본을 보호 저장소에 난수 이름으로 보관하고, 검증된 상대 폴더 경로만 프로젝트에 기록합니다. 지원하지 않는 문서나 숨김 파일은 자동으로 제외됩니다.

원본 파일은 수정되지 않으며 별도 thumbnail이 생성됩니다. DICOM에 개인정보 가능성이 있는 태그가 있으면 경고 아이콘이 표시됩니다. 경고 파일은 라벨러에게 배정하기 전에 기관 절차에 따라 검토하십시오.

### 작업 배정

1. **등록 영상 및 작업 배정**에서 **전체 데이터** 또는 원하는 폴더 이름을 눌러 하위 폴더와 영상을 확인합니다.
2. 폴더 안의 미배정 영상을 모두 배정하려면 폴더 오른쪽의 **폴더 전체 선택**을 누릅니다. 상위 폴더를 선택하면 모든 하위 폴더의 미배정 영상도 함께 선택됩니다.
3. 일부 영상만 배정하려면 폴더를 펼친 뒤 개별 영상 카드의 **선택** 체크박스를 사용합니다. 이미 배정된 영상은 선택 대상에서 자동으로 제외됩니다.
4. 화면 위쪽에서 선택된 영상 개수를 확인하고 라벨러를 선택합니다.
5. 필요한 경우 검수자를 선택합니다.
6. **이미지 배정**을 누릅니다.

선택할 사용자가 없다면 Sudo 관리자가 **관리자 > 사용자 관리**에서 라벨러 또는 검수자 계정을 먼저 생성해야 합니다.

### 승인 완료 결과 저장

프로젝트 관리자는 **승인 완료 결과 저장**에서 서버 Export 저장소의 하위 폴더와 형식을 선택할 수 있습니다. 승인된 작업만 저장되며 COCO, YOLO, PNG Mask, CSV 형식을 지원합니다. **원본 영상 포함**을 선택하면 ZIP의 `images` 폴더에 원본 영상도 함께 들어갑니다. 저장 기록의 **내 PC로 ZIP 다운로드**를 누르면 관리자 PC의 브라우저 다운로드 폴더에 ZIP 파일이 저장됩니다.

## 8. 단축키

입력창에 커서가 있을 때는 단축키가 실행되지 않습니다.

| 단축키 | 기능 |
|---|---|
| `W` | Bounding Box 도구 |
| `P` | Polygon 도구 |
| `B` | Brush 도구 |
| `M` | Pan/이동 도구 |
| `1`–`9` | 오른쪽 라벨 목록의 해당 순서 라벨 선택 |
| `Ctrl+S` | 수동 저장 |
| `Ctrl+Enter` | 작업 제출 |
| 마우스 휠 | 확대·축소 |

## 9. 자주 발생하는 문제

| 증상 | 원인과 해결 방법 |
|---|---|
| 로그인할 수 없음 | 계정 정보와 Caps Lock을 확인합니다. 반복 실패 시 관리자에게 잠금 해제를 요청합니다. |
| 작업이 보이지 않음 | 아직 배정되지 않았거나 프로젝트 멤버가 아닐 수 있습니다. 프로젝트 관리자에게 확인합니다. |
| 다른 사용자가 편집 중이라는 메시지 | 작업 잠금이 사용 중입니다. 잠시 기다린 후 다시 엽니다. |
| 영상이 표시되지 않음 | 네트워크, 파일 손상 또는 DICOM codec 문제일 수 있습니다. 파일명과 작업 ID를 관리자에게 전달합니다. 환자 개인정보는 메시지에 적지 마십시오. |
| `버전 충돌` 표시 | 다른 저장본이 존재합니다. 브라우저 새로고침으로 덮어쓰지 말고 작업 목록에서 다시 엽니다. |
| `오프라인 임시 저장` 표시 | 네트워크 연결을 복구한 뒤 같은 화면에서 **저장**을 누르고 `저장됨`을 확인합니다. |
| 제출 버튼을 사용할 수 없음 | 읽기 전용 상태이거나 이미 제출·승인된 작업인지 확인합니다. |
| DICOM 개인정보 경고 | 자동 안전 판정이 아닙니다. 기관의 비식별화 담당자에게 수동 검토를 요청합니다. |

오류를 보고할 때는 작업 ID, 발생 시간, 화면의 오류 문구만 전달하십시오. 환자 이름, 환자 ID, 원본 영상 또는 Annotation 전체를 일반 메신저와 이메일로 보내지 마십시오.

## 10. 현재 MVP 제한사항

- Multi-frame DICOM은 frame 수를 보존하지만 웹 UI의 frame별 탐색은 아직 제한적입니다.
- Brush의 부분 Eraser, Polygon 점 편집과 객체 이동·크기 변경은 아직 제공되지 않습니다.
- 브라우저 임시 저장본의 자동 복원 UI는 제공되지 않으므로 네트워크 복구 후 같은 화면에서 수동 저장해야 합니다.
- AI 사전 라벨, consensus/adjudication, DICOM SEG와 SSO는 확장 단계 기능입니다.
- 사용자 계정 생성은 Sudo 관리자의 **사용자 관리** 화면에서 할 수 있습니다.

운영상의 제한과 보안 정책은 [보안 문서](security.md) 및 [MVP 범위](requirements.md)를 함께 참고하십시오.
